# 🚀 StoryNodes

Plataforma web para criação, publicação e leitura de histórias interativas.
Permite que usuários escrevam suas próprias narrativas e explorem conteúdos criados por outros.

---

---

## ✨ Funcionalidades

* 📝 Criação de histórias
* 📚 Leitura de histórias publicadas
* 👤 Sistema de usuário (dashboard)
* 📊 Painel administrativo
* 🔎 Navegação entre conteúdos
